Privacy Policy

No tracking · No accounts
01
No telemetry

We don't track you.

This site collects no analytics, sets no tracking cookies, and has no accounts or logins. There is no usage telemetry and no backend database of visitors.

02
Dashboard data

Public server data only.

The dashboard reads the public open.mp server list (api.open.mp) and geolocates server IPs via geojs.io — both in your browser. It's about game servers, not you. Nothing about your visit is stored.

03
Third parties

What your browser fetches.

Pages pull a few public APIs directly (GitHub for repos/releases, open.mp for servers, geojs.io for map locations) and assets from jsDelivr/CARTO CDNs. Those providers may log requests at the network layer; Mac-Andreas neither receives nor correlates that data.

04
Hosting

Static on GitHub Pages.

The whole site is static files on GitHub Pages — no server-side code, no logins, no database we control. GitHub may log basic request metadata per its own privacy policy.
